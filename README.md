# AnomaliX 🛡️

**Anomaly-Based Network Intrusion Detection System**

AnomaliX is a machine-learning-based network intrusion detection project designed to identify potentially anomalous network traffic using the Isolation Forest algorithm.

## Features
- Upload network traffic data in CSV format
- Preview uploaded network traffic records
- Analyse traffic using an anomaly detection model *(integration in progress)*
- Display detection summaries and results *(planned)*

## Technology Stack
- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Joblib
- Matplotlib

## Project Status
The initial Streamlit interface has been developed. Integration with the trained machine learning model and cloud deployment are upcoming tasks.

## Dataset
UNSW-NB15 dataset.
